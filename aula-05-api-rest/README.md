# Aula 05 — Criando APIs para o Front-end

## Atividade 01
Servidor Express básico disponível em `atividade-01-servidor/`.

## Atividade 02 — CRUD de Notas
- `backend/`: API REST com GET, POST, PUT e DELETE
- `frontend/`: React consumindo a API
- `postman/`: coleção importável
- `RELATORIO.md`: roteiro do relatório final

## Execução local
Backend:
```bash
cd backend
npm install
npm start
```

Frontend:
```bash
cd frontend
npm install
npm run dev
```
