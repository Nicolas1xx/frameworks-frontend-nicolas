## Aula 05 — API REST

A Aula 05 integra front-end e back-end em um fluxo completo:

- servidor básico desenvolvido com Node.js e Express;
- API REST para o CRUD de notas, publicada no Render;
- front-end desenvolvido com React e publicado na Vercel;
- operações `GET`, `POST`, `PUT` e `DELETE`;
- [coleção Postman](aula-05-api-rest/postman/CRUD-Notas.postman_collection.json) para validação dos endpoints;
- [relatório da atividade](aula-05-api-rest/RELATORIO.md) com descrição técnica e evidências.
